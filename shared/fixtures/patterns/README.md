# Pattern regression fixtures

These nine JSON files preserve regression coverage migrated from earlier design
patterns. They are test inputs, not current authoring templates, and are not
distributed with either Skill. Their default `Card` surfaces and explicit
padding remain valid; do not rewrite them merely to match a design preference.

For current authoring guidance, use the
[Skill](../../../skills/dingtalk-aicard/SKILL.md) and its linked scenario examples.
